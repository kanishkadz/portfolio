# My Portfolio

Hi, I’m **Kanishka Anand**, and this is my personal portfolio website — a modern, responsive site built with **React** and styled using **Styled Components**. This project represents who I am, what I do, and showcases some of the projects I've worked on.

---

## 🌟 Features

* **🗂️ Project Showcase:** A clean and interactive display of my key personal and collaborative projects.
* **👨‍🎓 About Me:** A section that highlights my background, interests, and skills.
* **📱 Responsive Design:** Fully optimized for mobile, tablet, and desktop devices.
* **🎨 Custom Styling:** Built with Styled Components for scoped CSS, clean structure, and dynamic styling.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React
* **Styling:** Styled Components
* **Language:** JavaScript
* **Deployment Platform:** Vercel
* **Design Approach:** Minimal, professional, and user-friendly
